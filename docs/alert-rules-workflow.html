🎯 Acciones Disponibles
Acción Descripción Endpoint Agente
stop_encoder Detiene el encoder del canal POST /jobs/control?action=stop
start_encoder Inicia el encoder del canal POST /jobs/create
restart_encoder Reinicia el encoder (stop + start) POST /jobs/control?action=restart
failover Activa failover a señal de respaldo POST /api/internal/trigger-failover/{id}
notify_only Solo registra log y notifica (sin acción en encoder)

Flujo Principal
  • Alerta llega desde plataforma externa
  • Se normaliza a formato interno unificado
  • Se busca regla aplicable (específica → global → default)
  • Se ejecuta acción y se notifica
Búsqueda de Reglas
  • Prioridad: específica > global source > global total > default
  • Cooldown evita ejecuciones repetidas
  • Cada regla puede habilitar/deshabilitar notificaciones
Extensibilidad
  • Nueva plataforma: crear endpoint + normalizador
  • Las reglas existentes aplican automáticamente
  • Sin modificar código del motor de reglas
